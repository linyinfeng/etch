# 把 `lp.typ` 重排成一篇论证：过程与教训（2026-09-11）

- 范围：提交 `7b4dd12` → `6f5a274`（目标 `mtx1pmx4`，7/7 任务，独立审计通过）
- 问题：`lp.typ` 能自举、能渲染，但正文是"按序声明各个文件 + 附录里讲规则"——**能跑，不值得读**。要把它变成一篇以思路为骨架、以"它如何构建自己"为实例的文档，且**工具行为与全部闸门不变**。

## 结论（TL;DR）

1. **"重排没改一行代码"是可证的，而且 `--check` 证不了它**：重排前后各留一份纯净副本，逐个文件 `diff`（19 个全等）。`--check` 只证明"文档与磁盘一致"——它能给一次**错误**的重排开绿灯。**下次任何"行为不变"的搬运，先留"之前"的副本。**
2. **工具语义会变成写作约束**。三条都是机械后果，不是风格：chunk 名**全文档全局**（同名声明按序拼接）、**缩进引用的片段里不能有空行**（空行会被加上缩进 → 尾随空白 → `cargo fmt` 红）、**片段不能含它所在框架的收尾 `}`**（收尾括号留在骨架里）。
3. **自动改文档的脚本必须断言**。两处 `str.replace` 静默失败（搜索串里换行写成了空格），脚本打印 "applied"，我在提交说明里宣称修好了不存在的东西——被独立审计抓住。**这是本次最贵的教训。**
4. **机器能查的全绿 ≠ 文档是对的**。过期的头注释、指向已删附录的指针、10 个"有标题无散文"的小节：都是**读**出来的（先我通读，再审计读）。工具只能守机制，论证要读者。
5. **"同一条事实只在一处"可以机械查，但阈值不可靠**：253 个散文段落的 9-gram 交集扫出 4 处真重复（已修）；但词长 ≥3、阈值 9 会漏掉更短的措辞回声——审计就另指出两处。**判据是意图，不是那个数字。**
6. **代价可观**：目标运行 37 分钟、**1.5M tokens**；`lp.typ` 从 6109 行到 6157 行（散文 1304 行、244 个片段、19 章、15 个生成文件）。这是"人写级"文档编辑的单价，排计划时值得知道。

## 方法（可复用配方）

1. **留"之前"**：把要搬的生成文件 `cp` 到 `/tmp/*.before`；一章一提交，`lp.typ` 之外的任何东西都不动。
2. **从纯净副本抽取片段**（一次性脚本）：按行范围抽、`dedent`、`@` 转义、fence 长度自动（正文里有四反引号例子时用五个）、**缩进片段含空行直接报错**。
3. **根声明写成骨架**：`<<名字>>` + 少量真实行；片段定义在解释它的那一节里；顺序自由，所以章节可以随意搬运。
4. **每章的验收**：`tangle` → 与纯净副本 `diff`（必须为空）→ 四道闸门（`--check`、49 测试、fmt/clippy、demo、weave 0 警告）→ 提交。
5. **未搬的先聚在 `Not yet arranged` 下**，一次搬一个文件；搬完把那个小节删掉（否则文档里会留着"施工痕迹"）。
6. **收尾通读**：把 raw block 抽掉再读散文（1254 行），再请一个**独立读者**。

## 教训 A：关于这个工具与这个文档

| 事故 | 原因 | 结论 |
| --- | --- | --- |
| `map.rs` 一度被塞进 `explain.rs` 的开头（227 行） | 两章都声明了 `"the module note"`——**同名声明按文档顺序拼接** | 约定：私有片段带文件前缀（`map: …`）。**不**让工具去检查"跨章重名"：它看不见"章"，只能误报 |
| 缩进片段里的空行变成一行空格 | 引用点的缩进会加到片段的每一行 | 空行留在骨架里。改 `tangle`（不缩进空行）也能修，但那是**行为变化** → 要换种子 → 本次边界之外 |
| 片段的收尾 `}` 被挪位 | 同上：缩进属于引用点 | 收尾括号留在骨架里（写进 skill 的 Mechanics） |
| 生成文件里的模块注释 vs 文档里的论证 | 两处都在解释同一件事 | 注释是**指针**、不是第二份论证（成了 explain 那一章的正文） |
| 文档里留着"施工痕迹"：头注释说"正在重排"、规则章指向已删的"附录" | 搬家只改了结构，没回头读 | 每次搬完必须回头读那一节；`grep -i appendix` 之类要清零 |

## 教训 B：关于怎么干这件事

1. **断言式替换**：我中途才建 `sub(old, new)` 带 assert 的小工具——**一开始就该有**。没有断言的脚本输出 "applied" 什么都不证明。
2. **抽取源必须是纯净的**：`src/` 会被 `tangle` 重写；我曾从**被污染**的 `src/map.rs` 里抽片段，生成了一版 227 行的垃圾（幸好 `diff` 立刻发现）。
3. **`git checkout -- lp.typ` 会连未提交的章节一起回退**（丢过 `metadata`、`watch` 两章，靠 `/tmp` 的脚本重放补回）。所以：一章一提交，别把多章攒在工作树里。
4. **删除声明要按内容形状匹配**，不能按"第一个匹配"：`#file(path, …)` 的整文件声明与新插入的骨架同形，我两次删掉的是**新的**那个。
5. **独立审计值得**：它抓到我自己的结构检查抓不到的两条（不存在的"附录"指针、10 个无散文小节），代价远低于返工。它连续两次因基础设施中止，重试一次就过了——**中止不是驳回**，别把它当结论。

